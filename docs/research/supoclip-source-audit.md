# Supoclip source audit for a live chunk producer

Audited 2026-11-15 against current `main`, commit [`e42e93b02873d29e2000a6a8235c10e23f8c99c9`](https://github.com/FujiwaraChoki/supoclip/commit/e42e93b02873d29e2000a6a8235c10e23f8c99c9), committed 2026-11-15 20:28:02 UTC. Inspected source is at `/tmp/supoclip-audit-source`; the shallow clone at `/tmp/supoclip-audit-20261115` also resolves to this SHA. The application was not run and platform publishing was not tested.

## Verdict

Feasible as a completed-file clipping and publishing service behind an external live capture/chunk controller. Reuse its existing PostgreSQL/ARQ social publishing machinery, then add Facebook as another provider if required. The live producer still needs durable chunk tracking, absolute source timestamps, overlap/deduplication, backpressure, and a rule for selecting which generated clips to publish. Those are integration requirements inferred from the existing per-file task API; there is no live-stream ingest/session API. The source explicitly rejects videos without a verifiable positive duration as potentially still-live recordings. [Task/source admission](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/tasks.py#L92-L105), [task API](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/tasks.py#L582-L849).

## Actual API contract

**`/start-with-progress` is absent** from this commit's backend routes and API documentation. An integration based on that endpoint needs updating; the current lifecycle separates creation from progress streaming. [Router registration](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/main.py#L190-L219), [current API reference](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/docs/api-reference.md).

1. `POST /upload`: authenticated multipart form, **field `video`**, with optional `Idempotency-Key` (8–200 letters/digits/`.`/`_`/`:`/`-`). Response is `{"message":"Video uploaded successfully","video_path":"upload://<uuid>.<ext>"}`. The response follows durable local storage; object-storage copying may continue afterward. Identical bytes or retry keys reuse the existing upload; a reused key with different bytes returns 409. [Upload implementation](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/media.py#L395-L459), [deduplication/admission](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/repositories/upload_repository.py#L187-L242).
2. `POST /tasks/`: JSON `{"source":{"url":"upload://...","title":"optional"},"processing_mode":"fast","output_format":"vertical","clip_length":"short","add_subtitles":true}`. Response contains `task_id`, `job_id`, and a message. Optional fields include `font_options`, `caption_template`, `include_broll`, cleanup settings, `workflow`, `workflow_options`, and editorial `instructions`. Modes are `fast|balanced|quality`; duration presets are auto 15–60 s, short 15–30, medium 30–60, long 60–120. Model/provider selection is server configuration, not a per-request model field. Non-default workflows/instructions have rollout gates (`WORKFLOWS_ACCESS=admins` by default). [Creation parsing and response](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/tasks.py#L598-L849), [duration presets](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/clip_duration.py#L15-L28), [workflow configuration](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/config.py#L320-L328).
3. `GET /tasks/{task_id}/progress`: authenticated SSE; sends an initial `status`, subsequent progress/clip-ready events, and `close` on `completed|error|cancelled`. `GET /tasks/{task_id}` is the polling/recovery path; `GET /tasks/{task_id}/clips` returns `{task_id, clips, total_clips}`. Retrieve bytes with `GET /tasks/{task_id}/clips/{clip_id}/file?download=true`; local files stream directly, S3 files redirect with 307 to a temporary signed URL. Clips carry local start/end times, transcript text, and relevance/virality component scores, allowing the caller to filter before posting. [Task/clip reads](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/tasks.py#L929-L974), [SSE](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/tasks.py#L1012-L1070), [file retrieval](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/tasks.py#L1169-L1215), [clip fields](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/tasks.py#L443-L469).

There is no task-completed webhook field or callback route in the inspected API. Use polling as durable recovery even when SSE provides immediate notification. Source-level callbacks are internal worker callbacks. [Worker](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/workers/tasks.py#L122-L154).

## Authentication and Docker defaults

API keys are real: `Authorization: Bearer sk_...` or `x-api-key: sk_...`; their SHA-256 hashes resolve a database user, take precedence over frontend signed headers, and revocation is checked at use. API-key routes are registered unconditionally. Minting uses a signed frontend session and **requires `emailVerified`**, including self-hosting; the documentation says self-hosted installations need SES to deliver verification links. Thus an otherwise local/no-email installation has an API-key onboarding gap to configure. [Authentication](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/auth_headers.py#L31-L142), [minting checks](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/api_keys.py#L79-L117), [verification documentation](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/docs/api-reference.md#L7-L28).

`SELF_HOST=true` disables monetization, but authentication remains. `.env.example` has placeholder values for `BACKEND_AUTH_SECRET` and `APP_SETTINGS_ENCRYPTION_KEY`, with unsigned backend authentication false. Compose forwards these values; replace the placeholders. [Environment template](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/.env.example#L270-L282), [auth config](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/config.py#L203-L214).

## Native publishing is implemented

`POST /social/posts` accepts `task_id`, `clip_id`, `social_account_id`, plus title, caption, hashtags, privacy, and optional `scheduled_for`; returns `{post: ...}`. API keys may post/read, but OAuth account connection requires a frontend session. `GET /social/connections`, `GET /social/posts/{post_id}`, and `/retry` support orchestration. Creation stores a post row and enqueues ARQ work; scheduled posts are dispatched by a separate cron queue every minute. Claiming, persisted platform handles, retries, and uncertain-outcome handling reduce duplicate uploads. Reuse this queue instead of adding a second social scheduler. [Routes](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/social.py#L1-L7), [create-post contract](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/social.py#L212-L248), [durable creation/enqueue](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/services/social_service.py#L447-L573), [publication/recovery](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/services/social_service.py#L725-L992), [cron](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/workers/cron_worker.py#L63-L75).

## Stack, AI and rendering

Actual stack: Next.js 15.5/React 19/Better Auth/Prisma frontend; Python >=3.11/FastAPI/SQLAlchemy backend; PostgreSQL 15, Redis 7, ARQ workers. Compose includes API, frontend, render worker, AI edit worker and embedded cron, with shared uploads/clips volumes; remote render workers have S3-compatible storage support. [Frontend manifest](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/frontend/package.json), [backend manifest](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/pyproject.toml), [Compose](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/docker-compose.yml), [remote worker](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/docs/render-worker.md).

ASR defaults to AssemblyAI with word timing, speaker labels and language detection, preferring Universal-3.5 Pro with Universal-2 fallback; `ASSEMBLY_AI_SPEECH_MODEL=universal-2` is an explicit cheaper selection. Local OpenAI Whisper has word timestamps; Compose's default Whisper size is medium (bare config default base). YouTube captions are another provider but unsuitable for uploaded chunks. LLM analysis uses Pydantic AI and supports Google, OpenAI, Anthropic, OpenRouter and Ollama. Default inference prefers Gemini 3 Flash Preview if Google is configured, then GPT-5.2, Claude 4 Sonnet, or OpenRouter Sonnet 5.5 depending on keys; set `LLM` explicitly for reproducibility. [Transcription dispatch](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/media/transcription.py#L165-L205), [ASR settings](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/media/transcription.py#L321-L373), [models](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/ai.py#L508-L560), [default LLM](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/config.py#L507-L520).

Video work uses FFmpeg/libx264, ASS subtitles and OpenCV/YuNet face detection. CUDA Torch dependencies are available, but the inspected final encoder is CPU libx264; a GPU does not automatically make rendering GPU-encoded. The Docker image installs FFmpeg, Tesseract, fonts, Deno and Torch dependencies. `.env.example` selects CPU-only builds; Compose alone defaults to CUDA wheels and amd64. [Encoder](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/media/ffmpeg.py#L310-L335), [face detection](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/media/face_detection.py#L1-L51), [Dockerfile](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/Dockerfile).

## Practical risks to resolve in a pilot

- **Upload admission blocks continuous use by default:** 4 GB/file, three concurrent uploads and **20 new uploads per user per rolling day**; the daily check also applies to ordinary `/upload`, without a self-host exemption in that path. Increase the limit explicitly. Twenty 5-minute chunks cover only 100 minutes. [Defaults](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/config.py#L118-L159), [enforcement](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/repositories/upload_repository.py#L187-L242).
- **Throughput/latency is unproven:** one concurrent video job per user by default, four ARQ jobs globally per worker, with a three-hour video timeout. Social upload jobs share the worker function registry, so sustained render load can compete for slots. Measure end-to-end chunk-to-ready time; size chunks and workers so average processing completes faster than new work arrives. [User limit](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/config.py#L178-L188), [worker limits/functions](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/workers/tasks.py#L335-L377).
- **Deduplication is file/task based:** upload hashing and idempotency do not deduplicate semantically identical moments across overlapping chunk files, nor establish source-global clip offsets. Keep an external chunk manifest and compare absolute candidate intervals/transcripts before creating social posts. [Upload identity](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/repositories/upload_repository.py#L187-L242), [task identity](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/tasks.py#L562-L579).
- **Publication is not globally exactly-once:** source deliberately preserves unknown outcomes and avoids blind re-upload after lost responses. Reconcile platform/post status before retrying; application queue safety cannot guarantee remote API behavior. [Outcome/retry handling](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/services/social_service.py#L725-L975).
