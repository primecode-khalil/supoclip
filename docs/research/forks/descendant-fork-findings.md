## Metalbenji: verified implementation

- **Per-user BYOK and provider settings:** server code encrypts saved user keys, loads/decrypts them for AI requests and tries saved then environment keys; z.ai has separate subscription/metered profiles and routing. Providers are OpenAI, Google, Anthropic, z.ai and Ollama. Ollama supports a user-selected base URL and request options; this is not an unrestricted client-side provider SDK. [User key/profile resolution](https://github.com/Metalbenji/supoclip/blob/c9fa30c6ab54243be6de91847099a476ba6c1d09/backend/src/services/task_service.py#L1720-L1835), [actual model/provider construction](https://github.com/Metalbenji/supoclip/blob/c9fa30c6ab54243be6de91847099a476ba6c1d09/backend/src/ai.py#L776-L899).
- **Saved processing workflows and review UI:** presets include fast draft, balanced, best quality and stream layout; per-user preferences include transcription/provider/model/device/framing defaults. The backend persists editable draft clips and only queues reviewed selected drafts on finalization. [Presets](https://github.com/Metalbenji/supoclip/blob/c9fa30c6ab54243be6de91847099a476ba6c1d09/frontend/src/lib/processing-profiles.ts), [preferences API](https://github.com/Metalbenji/supoclip/blob/c9fa30c6ab54243be6de91847099a476ba6c1d09/frontend/src/app/api/preferences/route.ts), [draft editing/finalization](https://github.com/Metalbenji/supoclip/blob/c9fa30c6ab54243be6de91847099a476ba6c1d09/backend/src/api/routes/tasks.py#L2056-L2440).
- **ASR:** genuine local OpenAI Whisper model loading, CPU/CUDA device and GPU-index selection, model caching, configurable overlapping transcription chunks and word timestamps. AssemblyAI remains optional with a user key. This is standard `whisper`, not faster-whisper or WhisperX. A GPU timestamp exception retries without word timestamps, so output quality/timing needs empirical checking. [Device resolution](https://github.com/Metalbenji/supoclip/blob/c9fa30c6ab54243be6de91847099a476ba6c1d09/backend/src/whisper_runtime.py#L320-L371), [loading](https://github.com/Metalbenji/supoclip/blob/c9fa30c6ab54243be6de91847099a476ba6c1d09/backend/src/video_utils.py#L402-L420), [ASR and fallback](https://github.com/Metalbenji/supoclip/blob/c9fa30c6ab54243be6de91847099a476ba6c1d09/backend/src/video_utils.py#L775-L810), [chunked ASR](https://github.com/Metalbenji/supoclip/blob/c9fa30c6ab54243be6de91847099a476ba6c1d09/backend/src/video_utils.py#L964-L1085).
- **GPU rendering and subtitle styling:** real NVENC candidate when CUDA and FFmpeg encoder capability are detected, followed by a CPU candidate. The render path actually iterates candidates and renders ASS captions through FFmpeg. This is a further GPU donor worth retaining alongside stale2000, though adoption requires porting from a large old module. [Encoder construction](https://github.com/Metalbenji/supoclip/blob/c9fa30c6ab54243be6de91847099a476ba6c1d09/backend/src/video_utils.py#L341-L399), [render call path](https://github.com/Metalbenji/supoclip/blob/c9fa30c6ab54243be6de91847099a476ba6c1d09/backend/src/video_utils.py#L4075-L4225).

## Requested live/archive/publishing capabilities

No live capture controller, persistent live-session/chunk archive, stream reconnect logic, rclone transport or social-account publisher was found in the checked source tree. Keyword matches for publishing refer to Redis progress events; TikTok/Instagram mentions describe output format/fonts. The `stream_layout` preset changes framing and processing defaults for an already supplied video; it does not capture an active stream. Transcription chunk overlap similarly applies to an existing media file. [Stream preset](https://github.com/Metalbenji/supoclip/blob/c9fa30c6ab54243be6de91847099a476ba6c1d09/frontend/src/lib/processing-profiles.ts#L84-L97), [source tree](https://github.com/Metalbenji/supoclip/tree/c9fa30c6ab54243be6de91847099a476ba6c1d09/backend/src).

## Recommendation and integration limits

Keep current upstream as the base. Add Metalbenji to the donor shortlist for user settings/BYOK, review-before-render workflow and NVENC/ASS rendering; it does not remove the live archive or Facebook-publishing work. The broad historical divergence makes replacing upstream costly. Before reusing its multi-user key APIs, adapt identity to the current authenticated user: this fork accepts a supplied `user_id` header in backend helpers, and encryption has a fixed development fallback unless configured. [Identity helper](https://github.com/Metalbenji/supoclip/blob/c9fa30c6ab54243be6de91847099a476ba6c1d09/backend/src/api/routes/tasks.py#L524-L528), [secret handling](https://github.com/Metalbenji/supoclip/blob/c9fa30c6ab54243be6de91847099a476ba6c1d09/backend/src/services/secret_service.py#L24-L48). These are source findings; throughput, GPU compatibility, ASR accuracy and full end-to-end correctness were not measured.
