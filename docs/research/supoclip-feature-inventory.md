# SupoClip feature inventory: preserve the whole product

Audited 2026-11-15 at [`e42e93b02873d29e2000a6a8235c10e23f8c99c9`](https://github.com/FujiwaraChoki/supoclip/commit/e42e93b02873d29e2000a6a8235c10e23f8c99c9), using the checked-out source at `/tmp/supoclip-audit-source`. This expands the earlier capture/publishing audit: routes, services, editor documents, frontend screens, configuration and test files were inspected. **Implemented** means a reachable code path exists; **gated** means implemented behind configuration, provider credentials or entitlement; **limited** identifies a material boundary. No application, paid provider, OAuth integration or render was executed for this inventory.

The `SC-01`–`SC-10` identifiers below are stable feature-group IDs for a merged-product acceptance checklist. Workflow subfeatures are `SC-02a`–`SC-02e` in table order. Route reachability was checked against the production `src.main:app`; `main_refactored.py` is a compatibility import of that same application, not a second development-only feature set. ## SC-01. Inputs and creation

**Implemented:** YouTube URLs, including canonicalization of watch/share/Shorts/embed/live-shaped links to a video ID; Twitch VODs and clips; Kick VODs and clips; local uploaded video. Twitch/Kick channel pages are rejected with a VOD/clip hint. These are completed-video imports, not live monitoring or continuous recording. Positive duration and source-length admission checks happen before charging. [Task admission](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/tasks.py#L598-L724), [stream URL patterns](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/stream_source.py#L89-L97).

Uploads support an API multipart path and direct-to-object-storage multipart authorization/part refresh/complete/abort. Content hashing, retry keys and active-source admission avoid accidental duplicate tasks. Import logic supports audio-first analysis and selected-section downloads; Twitch/Kick use configurable proxy/direct/Apify provider chains, including HLS section fetching and recoverable signed media resolutions. Keep these completed-VOD adapters alongside pyauto's live capture. [Upload routes](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/media.py#L395-L540), [stream resolution/download](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/stream_source.py#L1155-L1386).

Creation exposes subtitle on/off, caption template and font styling, B-roll, cleanup, output framing and clip length. API/MCP also expose fast/balanced/quality processing. Auto/short/medium/long mean 15–60/15–30/30–60/60–120 seconds for highlights, before cleanup. Account creation defaults retain workflow, template, framing, B-roll, cleanup and per-workflow lengths/advanced settings; topic, instructions and part count are per-video. The composer recognizes a pasted URL plus prose, moves prose into instructions with undo, and suggests workflows from multilingual wording. [Creation contract](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/tasks.py#L610-L645), [saved settings](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/frontend/src/lib/create-settings.ts#L4-L65), [composer recovery/suggestions](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/frontend/src/components/home-app.tsx#L442-L546).

## SC-02. Five editorial workflows, not just highlights

All have actual planners/render integration. Plain highlights are always available; customization and other workflows are **gated** by both the per-platform database flag and `WORKFLOWS_ACCESS`, with allowlisted verified emails and `WORKFLOWS_PUBLIC` exceptions. Defaults restrict rollout; lack of visible UI does not mean absent implementation. [Access evaluation](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/workflows/options.py#L231-L310), [planner dispatch](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/workflows/pipeline.py#L19-L29).

| Workflow | Preserve its distinct behavior and controls |
|---|---|
| Highlights | Independently ranked moments, maximum clip count, optional editorial instructions. |
| Series | Ordered multi-part story, automatic or 2–10 parts; cold open, part labels, cliffhanger/natural endings, best chapters/start-to-finish coverage. |
| Topic | Extract clips about a specified subject; broad/strict matching and maximum results. |
| Recap | One assembled summary; on-screen points, 30–150-second target, 2–12 points and whole-video/best-moments coverage. |
| Trailer | One teaser; 20–60-second target, strict/relaxed spoilers and automatic/question ending. |

Planned workflows additionally control hook titles and automatic/soft/hard junctions. They store a plan, source ranges, part/point/beat metadata and explanatory notes; results preserve series order and single-output recap/trailer presentation. Preserve their workflow-specific duration budgets rather than applying highlight length rules globally. [Advanced registry](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/workflows/settings.py#L52-L85), [request validation](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/workflows/options.py#L108-L205), [result presentation](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/frontend/src/app/tasks/%5Bid%5D/page.tsx#L787-L816).

## SC-03. Selection, transcription and cleanup

**Implemented/configurable:** AssemblyAI word timestamps, language detection and diarization; local Whisper; YouTube caption transcription. Clipping LLM adapters cover Google, OpenAI, Anthropic, OpenRouter and Ollama. Fast mode can use a cheaper speech model and fewer clips. Analysis produces summary/key topics, transcript-grounded candidate text, reasoning, relevance, hook type and virality components (hook, engagement, value, shareability); opening refinement and picture checks remove weak openings/static slates and retain ranked reserve candidates. These are separate editorial policies worth preserving alongside pyauto's candidate selection. [Transcription dispatch](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/media/transcription.py#L165-L205), [model adapters](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/ai.py#L508-L560), [selection pipeline](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/services/video_service.py#L1231-L1316).

Long-pause removal defaults to 1.2 seconds, with 250–3000 ms configurable threshold. Filler removal has English/German/French and language-neutral lists, plus user-defined words/phrases. Both default on for new tasks, allow explicit opt-out and can be reapplied through task settings. Preserve the actual cut ranges and caption remapping, not only cleaned transcript text. [Cleanup semantics](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/clip_cleanup.py#L9-L108).

**Absent:** automatic caption translation and dubbing. The product explicitly says it captions the spoken language; mixed-language reliability is limited. UI localization is a separate implemented feature. [Product language contract](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/frontend/messages/en/marketing.json#L510-L521).

## SC-04. Framing and captions

**Implemented:** five generation formats: automatic vertical, full-frame vertical fit, speaker pan, two-person split and original aspect. Automatic vertical includes face tracking, scene-aware fit/crop composition, slides/graphs/content preservation, slow static punch-in, reaction inset separation, per-shot interviews, stacked video-call tiles, stage/gallery layouts, diarized active-speaker crops and overlapping-speaker panels. Caption/hook placement adapts to faces/layouts. These are substantial render alternatives, not one generic center crop. [Format registry](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/media/common.py#L65), [automatic layout implementation](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/media/reframing.py#L1465-L1660), [explicit pan/split/fit](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/media/reframing.py#L1791-L1856).

Seven real caption templates: Default, Hormozi, MrBeast, Minimal, TikTok, Neon and Podcast. Settings include fonts, size/colors, active-word highlights/pills, emphasis, outline/shadow/glow, emoji, uppercase, line length, position and animation. Tesseract-based detection avoids placing new captions over existing burned captions; it does not remove source captions. User-specific TTF/OTF upload/delete is implemented, **paid-gated** in hosted mode, with fonts copied to media storage for remote workers. [Templates](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/caption_templates.py#L21-L183), [caption-band avoidance](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/video_utils.py#L454-L486), [font upload](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/media.py#L208-L274).

## SC-05. Clip Studio and legacy editing

**Implemented:** non-destructive studio with canvas preview, filmstrip/waveform timeline, precise trim, split/duplicate/remove/reorder segments, preview loop/speed, word/text/timestamp correction, word occurrence emphasis, hook text/timing, independently movable/scalable hook/caption layers and per-caption transforms. Vertical/square/original framing, contain/cover/automatic layouts, zoom and anchors; exported gain/mute; brightness, contrast, saturation, blur and hue. Undo/redo, keyboard shortcuts, reset-to-original, device caption presets, apply style across task clips and ordered combination into a new clip retain originals. Preview speed does **not** alter export speed. [Document contract](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/editor_document.py#L31-L172), [studio controls](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/frontend/src/components/editor/inspector.tsx#L127-L865), [documented supported behavior](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/docs/editor.md#L1-L56).

Drafts autosave with optimistic revisions, server/current-draft persistence and local recovery/history. Conflict handling retains local changes; downloadable JSON backups, browser-cache management and preview rebuild with replaced-draft backup are real recovery features. Studio prepares clean source media instead of captioning an already burned clip. It re-downloads remote sources when needed and checks complete coverage. **Limited:** studio supports four built-in fonts and substitutes unsupported generation/custom fonts. [Recovery](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/frontend/src/components/editor/use-editor.ts#L200-L295), [backup/rebuild API](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/editor.py#L165-L212), [font substitution](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/services/editor_service.py#L173-L202).

Legacy committed APIs still trim, split, merge, rewrite captions, regenerate and apply project-wide settings. Preserve these API compatibility paths separately from studio drafts. Neither interface establishes a general whole-source timeline for manually authoring arbitrary new moments. Source maps store discontinuous original ranges and actual output offsets (including crossfades); losing them breaks recap/trailer edits, captions, B-roll and later source reconstruction. [Legacy routes](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/tasks.py#L1291-L1457), [source-time mapping](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/clip_source_map.py#L149-L196).

## SC-06. AI editing and stock footage

**Implemented/configuration-gated:** plain-language editing runs on a separate AI queue; it keeps/cuts/reorders ranges, removes words/pauses, corrects/highlights caption words, changes caption/hook/framing/effect/audio settings, and adds/removes/moves B-roll. It returns a validated document and change summary. Anthropic is the hosted dependency; `AI_EDIT_MODEL=ollama:*` is an explicit alternative. Hosted monthly reservations/refunds enforce Pro/Creator allowances; self-host bypasses monetary limits. Music, voiceover, stickers, speed changes and arbitrary transitions are explicitly outside the operations. [AI operations/settings](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/services/ai_edit_service.py#L55-L189), [provider availability](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/services/ai_edit_service.py#L561-L566), [allowances](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/services/ai_edit_allowance_service.py#L12-L73).

Pexels B-roll supports automated generation-time cutaways, editor search/pagination, AI suggestions avoiding existing placements, footage previews/credits, timed placement/offset/fades and removal/movement. B-roll follows source-time cuts, reorder and duplication; server and browser rendering both consume it. Requires Pexels configuration; there is no general user stock-media upload library here. [Editor endpoints](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/editor.py#L475-L574), [mapping semantics](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/editor_document.py#L270-L298).

## SC-07. Review, library, sharing and exports

**Implemented:** live SSE progress/early clip-ready events, resumable failed/cancelled tasks, title updates, clip previews and scores/reasons/transcripts; score/timeline sorting, focused clip viewer, single/bulk task cancellation/retry/deletion. Library searches titles, filters ready/active/attention, sorts newest or groups generations by original video. These groups are not user-created folders, collections or collaborative projects. Public tokenized result links can be created/revoked; public readers receive a sanitized task and clip media access. [Library behavior](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/frontend/src/app/list/page.tsx#L327-L470), [sharing APIs](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/tasks.py#L880-L1010).

Downloads: original generated MP4, all-clips ZIP with preflight/recovery, queued TikTok/Reels/Shorts re-encodes, studio background exports with status/cancel/download and sequential batch exports, plus browser WebCodecs exports. Server is H.264/AAC; browser prefers AAC but can produce MP4/Opus. Studio respects chosen aspect; legacy platform presets target 1080×1920 and 10/12/10 Mbps. Browser/server text rasterization differs and server alone draws power-word emphasis/emojis. **Not found:** standalone SRT/VTT download. The editor JSON backup is editing state, not a subtitle export. [Preset definitions](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/clip_editor.py#L29-L41), [ZIP](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/backend/src/api/routes/tasks.py#L1219-L1289), [export engines/queue](https://github.com/FujiwaraChoki/supoclip/blob/e42e93b02873d29e2000a6a8235c10e23f8c99c9/docs/editor.md#L37-L56).

## Do not lose in the merge

1. Keep **both** automatic/prompted candidate selection and human clip editing; preserve all five Supo workflows and useful pyauto selection alternatives behind one job contract.
2. Keep completed uploads/VOD imports beside live capture; add stream/session/chunk provenance without overwriting Supo source-range maps.
3. Retain every framing mode, template, custom-font path, cleanup control, B-roll path and server/browser rendering alternative, with accurate compatibility labels.
4. Preserve draft/original separation, undo/recovery/backups, legacy mutation APIs, ZIP/preset/batch exports and public shares.
5. Preserve multi-account scheduling, provider reconciliation, metrics and the ranking feedback loop; explicitly join editor export artifacts to publishing.
6. Preserve account/auth/API/MCP, billing entitlements/self-host mode, preferences/localization, admin rollout and support surfaces. New product branding must not silently remove existing accounts' access or assets.

**Do not count stubs as complete features:** `/transitions` and the MCP transition-list tool exist, but standalone generation deliberately disables inter-clip transitions. Workflow internal junctions and B-roll fades remain real.
